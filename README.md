# ThermalForge — PC Cooling Studio (Vibe Coding Project)

An interactive PC cooling simulator for estimating CPU/GPU temperatures, visualizing PC builds in 3D, comparing air vs liquid cooling, and finding the right CPU cooler.

## Features

- **PC Thermal Estimator** — Estimate CPU and GPU temperatures based on hardware and cooling configurations.
- **3D PC Build Visualization** — Explore a visual representation of your PC build.
- **Air vs Liquid Cooling Simulator** — Compare different cooling solutions and their potential performance.
- **Cooler Finder** — Explore CPU cooler options for your build.
- **Advanced Heatsink Lab** — Learn about heatsink designs and the principles behind heat dissipation.
- **Theme Support** — Switch between dark, light, and system themes.

## Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/NhanhCRGB/ThermalForge.git
   ```

2. Open the project folder.
3. Open `ThermalForge.html` in a modern web browser.

Alternatively, rename `ThermalForge.html` to `index.html` if you plan to deploy the project using a static website hosting service.

An internet connection may be required to load external libraries and fonts.

## Notes and Limitations

- Temperature readings are **estimates generated by simplified thermal models**, not actual measurements from your computer.
- Cooling performance varies depending on hardware, ambient temperature, case airflow, fan speeds, and other real-world conditions.
- Component prices and specifications may be approximate and may not always reflect current market information.
- Cooler recommendations should be checked against the compatibility requirements of your actual hardware.
