# ThermalForge — PC Cooling Studio

**Keep your PC cool and quiet, without the guesswork.**

ThermalForge is an interactive PC cooling simulator designed to help users understand computer thermals, explore cooling configurations, and make informed decisions about PC cooling. By combining configurable hardware specifications, estimated thermal performance, and interactive 3D visualization, ThermalForge makes PC cooling easier to understand.

## Features

- **PC Thermal Analysis** — Configure your CPU, GPU, CPU cooler, case, fan layout, and other cooling-related settings to estimate temperatures and noise levels.
- **Interactive 3D Visualization** — Explore a 3D representation of your PC build, rotate the model, and inspect airflow behavior.
- **Air vs. Liquid Cooling Lab** — Compare up to four coolers in simulated stress-test scenarios and evaluate their estimated thermal performance.
- **Cooler Finder** — Discover suitable CPU coolers based on budget, case compatibility, processor requirements, and personal priorities.
- **Advanced Heatsink Lab** — Experiment with thermal interface materials, heatsink designs, fin configurations, and airflow parameters to understand heat transfer.
- **Cooling Recommendations** — Explore suggested improvements to airflow, fan configuration, and cooling performance.
- **Responsive Interface** — Navigate the tools through a modern interface with light, dark, and system appearance modes.

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/NhanhCRGB/ThermalForge.git
   ```

2. Open the project folder.

3. Launch `ThermalForge.html` in a modern web browser.

   Alternatively, rename the file to `index.html` to use it as the default entry point for static website hosting.

The website loads several libraries and fonts from external CDNs, so an internet connection is required for those resources.

Notes and Limitations

Temperature readings are estimates generated by simplified thermal models, not actual measurements from your computer.

Cooling performance varies depending on hardware, ambient temperature, case airflow, fan speeds, and other real-world conditions.

Component prices and specifications may be approximate and may not always reflect current market information.

Cooler recommendations should be checked against the compatibility requirements of your actual hardware.
